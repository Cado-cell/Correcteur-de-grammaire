# Correcteur de grammaire

Correction orthographique et grammaticale du français dans le navigateur, avec
[Grammalecte](https://grammalecte.net/).

Le projet se trouve dans **[`grammalecte-chrome/`](grammalecte-chrome/)** :

* `grammalecte-chrome/server.py` — serveur local Flask exposant Grammalecte sur
  `http://localhost:5001` ;
* `grammalecte-chrome/extension/` — extension Chrome (Manifest V3) qui souligne
  les fautes dans les champs de saisie de n'importe quelle page.

Instructions d'installation et de lancement :
**[grammalecte-chrome/README.md](grammalecte-chrome/README.md)**.
